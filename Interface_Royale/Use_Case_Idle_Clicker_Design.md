# Use Case Design: Idle Clicker — "Tap Tycoon: Factory Frenzy"

Version: 0.1 (2025-09-04)

## Pitch
One-thumb idle clicker where players tap to produce widgets, invest in automated stations, and trigger time-limited boosts. Core loop: Tap → Earn → Upgrade → Automate → Prestige. Social: light clans with donation boosts and shared milestones.

## Core Loop & Sessions
- Session: 30–90s bursts to claim income, trigger boosts, and buy upgrades.
- Offline: accrual capped at 8–12h; collect on login.
- Appointments: Daily goals, limited-time boost events, rotating booster shop.

## Screens (mapped to Interface Royale template)
1) Home (Lobby)
- Header: Player level, widgets/min, coins, gems, season timer.
- Primary CTA: "Play" opens Tap screen directly. Widgets: Daily goals, Boost queue, Season track.
- Banner: Event of the day, Starter bundle.

2) Play (Tap Screen)
- Canvas: Large factory machine with tappable hotspot; progress meter.
- Bottom HUD: Tap button, 4 quick-boosts (x2 income, auto-tapper, crit chance, speed), timer chips.
- Overlay: Offline earnings collect; combo meter; fever time bar.

3) Upgrades
- Tabs: Machines, Managers, Boosters.
- Cards: Each upgrade shows current level, next bonus, cost; green if affordable.
- Detail: Descriptions, milestones unlock additional effects.

4) Collection (Skins & Cosmetics)
- Grid: Machine skins, tap effects, trails, background themes.
- Rarity: Common → Mythic; duplicate conversion → dust.

5) Events
- Rotating mini-modes: "Golden Hour" (crits only), "Automation Rush", "No Tap Challenge".
- Event rewards: cosmetics, keys, season XP.

6) Clan (optional at Lvl 5)
- Clan Boost: Group meter fills from members' production; triggers 10m global x2.
- Donations: Request/Donate booster cards.

7) Shop & Offers
- Lanes: Daily Deals (boosters, keys), Bundles (starter, progression), Currency (gems), Cosmetics.
- Rewarded Ads: +50% offline claim, free reroll, extra quest.

8) Season Pass
- Free + Premium tracks with production multipliers, cosmetics, and skip tokens.

9) Reward Reveal
- Crate opening: reveal boosters/skins with escalating rarity; duplicates → dust.

10) Settings
- Haptics, SFX, language, account.

## Economy
- Currencies: coins (soft), gems (hard), keys (crates), dust (dupe conv.).
- Sources: tap income, passive stations, quests, events, pass tiers.
- Sinks: upgrades, crafting cosmetics, re-rolling quests, event entries (keys).
- Timers: booster cooldowns, event windows, daily shop reset.

## Retention & Monetization
- D0: FTUE to first upgrade, free cosmetic crate, starter bundle surfacing.
- D1: Daily goals unlock, ad-boosted offline claim, first season pass quest.
- D7: Clan unlock, event intro, mastery milestones.
- Monetization: curated daily deals, starter/progression bundles, pass, cosmetics, rewarded ads for speedups/bonuses.

## Accessibility & UX
- One-thumb ergonomics; large tap target; clear progress and timers.
- Red-dot hygiene; always-resolvable notifications; claim-all actions.

## KPIs to watch
- D1/D7/D30 retention, ad opt-in rate, pass uptake, ARPDAU, payer conversion, depth, session frequency/length.
