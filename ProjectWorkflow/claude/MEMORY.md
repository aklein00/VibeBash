# MEMORY.md

Memories for this example do not live in this file.

They live in `ProjectWorkflow/vault`. Start at `vault/Home.md`. Product context starts at `vault/products/Fieldnote/Fieldnote.md`. Session context starts at the index of the latest file in `vault/daily/`.

Do not copy those notes into this file. Do not create a new memory file when something should be appended to the vault.

Risk: if this pointer is wrong, Claude goes back to its default memory directory and the vault stops being the shared record. Cursor and Codex never read this file. They have their own copies of the pointer.
