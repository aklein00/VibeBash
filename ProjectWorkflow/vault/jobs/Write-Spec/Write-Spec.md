# Write-Spec

Index note for a code change that is not ready to make yet. The spec is appended to [[campaigns]] only if it is about the member site. Otherwise append it to today's daily note under Detail, and put one line in the index.

1. Read [[Fieldnote]] and [[codebase]].
2. Read today's daily note index so you do not restate a decision already logged.
3. Write the change in a few lines: what a member can do afterward, what stays the same, what is out of scope.
4. Name the repo from [[codebase]]. If the repo line is still the placeholder, say the spec cannot be implemented yet.
5. List the files you expect to touch. Guessing a path you have not opened is a risk. Say "not opened" instead of inventing one.
6. Say how you will know it worked.
7. Do not edit code in this job. Implementation is [[Ship-Change]], and it belongs in Cursor or Codex.
8. Append the daily index: "spec written, not shipped."
