# Create-Campaign

Index note. Eight steps. Each step links out. Boot command: "We're going to create a campaign. We're going to do this offer."

A campaign here is the offer, the sales page, and the order form. The draft is appended to [[campaigns]]. It is not published.

1. Read [[Fieldnote]]. Follow its links before writing anything.
2. Read [[offer]]. Sell that offer. Do not invent a new one.
3. Read [[audience]].
4. Read [[scoreboard]]. If churn or revenue is still the sample zero row, say so in the draft and stop short of a finished page.
5. Write the hook only after those four notes. One sentence. Append it under a new dated section in [[campaigns]].
6. Outline the sales page in that same section: promise, proof, price, trial, cancel.
7. Outline the order form: plan, price, trial length, what happens on day 15.
8. Append one index line to today's note in `vault/daily/`. Mark the page "not approved."

Stop. A person approves the page. This job does not send email and does not create ads. Those are [[Draft-Email]] and [[Make-Ads]].
