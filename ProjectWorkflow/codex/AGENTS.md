# AGENTS.md

Instructions for a Codex run started in `ProjectWorkflow/`. A copy of this file at the repository root would govern every Codex task in VibeBash, including the game and Maya projects. Leave it here unless that is what you want.

## Memory

Read `../vault/Home.md`, then the index of the latest file in `../vault/daily/`, then the job note you were given. Follow that note's links. Do not load the whole vault first.

Append the result to the note the job names. Append one index line to today's daily note. Make a new note only for a new product, a new job, or a new day.

## Writes

- You may append `../vault/daily/` and the draft note the job names (for Fieldnote, `../vault/products/Fieldnote/campaigns.md`).
- You may edit source files only when the job is Ship-Change and a spec names those files.
- Do not reorganize, rename, or "clean up" the vault.
- Do not add secrets, and do not print secrets into the vault. This repo is public.
- Do not send email, publish a page, or spend money. Stop at the draft.

## How this place differs

Codex is the better place when the job note is already a spec and nobody needs to watch each step. It is the worse place to explore the vault. An unattended run will edit anything this file allows, and a wide allow-list becomes a rearranged notebook. Obsidian plus Claude Code is the better place to write and consolidate the notes. Cursor is the better place when a person should see the diff before it lands.

Codex on a cloud clone sees this git repo. It does not see a vault that lives only in the Obsidian app on your computer. If `AGENTS.md` is only at the repo root and this folder's copy has drifted, follow the root file and say that the two copies disagree.
